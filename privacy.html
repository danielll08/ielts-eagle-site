Privacy Policy

IELTS Eagle is used only by its owner to upload the owner's own videos to the owner's own TikTok account.

Data we access

  • Basic TikTok profile information of the owner's account (open ID and display name) via the user.info.basic scope, used only to confirm the correct account is connected.
  • Permission to upload videos to the owner's TikTok inbox via the video.upload scope.

Storage

The access and refresh tokens issued by TikTok are stored only on the owner's computer, outside any code repository. They are never sent to any server other than TikTok's official API, never shared and never sold.

Other people's data

The tool does not collect, store or process personal data of any other TikTok user or viewer. There are no analytics, cookies, advertising or tracking on this website or in the tool.

Deletion

The owner can disconnect at any time by revoking the app in TikTok settings and deleting the local token file; all access ends immediately.
